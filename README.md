# SHEIN → eBay 选品工具

给 eBay（澳洲站 / 美国站）做 SHEIN 一件代发用的选品工具：**自动**从希音分类页/搜索页找商品，
抓标题、变体、库存、价格、图片，按规则生成 eBay 标题和价格，最后出一份可以直接用来上架的汇总表。

不用手工喂链接，脚本自己翻页找货。

支持 **Windows 10/11（64 位）** 和 **macOS（Apple 芯片 / Intel）**。

## 功能

- **自动找货**：给一个希音分类页/搜索页链接，脚本自己往下翻页，把商品卡片全抓下来
- **严格按页面顺序抓**：页面上从左到右、从上到下，看到第几个就抓第几个 —— 不做任何重排，
  保证"你在屏幕上看到的那一批"就是抓的那一批（可复现）
- **可选：自动加价格筛选 + 自动翻页**（默认关）：打开后会把 `min_price/max_price` 写进链接、
  并翻 `page=2、3…`，候选池更"对价"、产出率高很多，但**商品集合会变**（不再等于你看到的那页）
- **逐件抓详情**：标题 / 卖家 / 变体（规格、颜色）/ 每个变体的 sku、库存、价格 / 图集
- **评分门槛**：抓商品星级和评价数，**低于设定分数（默认 4 分）直接跳过**；
  列表页的销量（`700+ sold`）和爆款标签（`#1 Bestseller`）也一并抓进表里
- **库存门槛**：每个变体库存要够（默认 ≥10 件才要）——希音显示 `Only N left!` 就是库存紧张，
  一件代发最怕"卖出去了却断货"，这类直接不要
- **禁品 / 大牌过滤**：标题命中就不抓（连商品页都不打开），内置
  **儿童用品（kid/child/baby）· 精油香薰 · 洗发水护发素 · 大牌（LV/Chanel/Dior/Nike…）**，
  还能在界面「追加禁品词」里自己加
- **Local（本地仓）过滤**：希音标记 Local 的商品默认不抓
- **Oops 自动刷新**：希音自己的报错页（`Oops!` / `Something went wrong`）会自动刷新重试 3 次
- **按规则筛**：价格区间可填（澳洲站 9–30 AU$、美国站 10–35 $ 有快捷预设）；
  每个商品固定挑 N 个有库存、且每个都在区间内的变体（N 由界面「变体个数」控制，默认 3，不够就有多少挑多少）
- **标题改写**：≤80 字符，去掉 `1pc` 这类一件代发标记、品牌词、垃圾词、风险词，
  美式拼写改澳式（organizer→organiser、gray→grey、jewelry→jewellery…）
- **多选自动定值**：标题里的 `2/3 Tier`、`6/8/12/20 Colours` 这类多选，会按选中的变体定成一个值；
  定不下来会在备注里提示，并把每个版本的标题写进商品文件夹的 txt
- **同系列自动多抓**：一条链接挂了多个色块（希音把同系列商品挂在同一条链接里，每个色块是独立商品）时，
  随机多抓几个，不用人工判断
- **去重**：自动读你的主表（所有工作表）+ 输出目录里已有的汇总表和商品文件夹，
  再加一份工具自己的全局记录（`_已选过记录.txt`，换输出目录也不会重复）；
  已经出现过的商品不再重复上，实在重复了会在备注写「疑似重复」
- **图片**：商品文件夹里存 6 张图；汇总表里内嵌第一张图
- **汇总表**：一个工作簿、多张工作表，按编号区间分页（`备份109-125`、`备份126-150`…），
  每跑一批自动新建一张表往后接，不会覆盖
- **不硬刚反爬**：抓取节奏可选（默认「稳妥」= 每个商品间隔 10~20 秒、每 6 个再歇 30~60 秒）；
  遇到人机验证/登录墙自动歇一会儿重试，或按设置跳过；还有「换新会话」一键换访客会话
- **断点不丢**：每抓一件就落一次表；编号接着已有内容排；同一输出目录只允许一个任务在跑

## 下载安装（给同事用，不需要装 Python）

打开仓库的 **Releases** 页面，按系统下载对应压缩包，解压就能用：

| 系统 | 下载 |
|---|---|
| Windows 10/11（64 位） | `SHEIN选品工具-Windows-x64.zip` |
| Mac（Apple 芯片 M1/M2/M3…） | `SHEIN选品工具-macOS-arm64.zip` |
| Mac（Intel 芯片） | `SHEIN选品工具-macOS-x86_64.zip` |

- **Windows**：解压后双击 `SHEIN选品工具.exe`
- **macOS**：解压后把 `SHEIN选品工具.app` 拖进「应用程序」，**第一次要右键 →「打开」**
  （未签名，直接双击会被系统拦一次），之后正常双击
- 推荐安装 **Microsoft Edge**；也支持 Google Chrome
- Mac 版的数据（浏览器档案、全局记录）存在 `~/Library/Application Support/SHEIN选品工具/`；
  Windows 版存在 exe 同目录的 `_chrome_profile/`

## 源码方式运行

```
pip install -r requirements.txt
```

- Windows：双击 `run.bat`
- macOS：双击 `启动.command`
  （第一次可能要在终端执行一次 `chmod +x 启动.command`）

界面上：

1. **抓取模式**：默认「从希音分类/搜索页自动抓商品」
2. **浏览器**：默认选 `Edge`。Edge 模式会复制当前 Edge 的 Default 档案到工具的
   `_edge_profile`，用于保留登录、Cookie 和页面优惠价格。首次使用会关闭正常 Edge，
   再以抓取模式重新拉起；请先保存 Edge 中正在编辑的内容。
3. **分类/搜索页**：填希音的**分类页或搜索页**链接（**别填首页**，首页没有商品卡片），例如
   `https://au.shein.com/Beauty-Health-c-1864.html`（澳）
   `https://us.shein.com/Women-Dresses-c-12472.html`（美）
4. **抓取个数**：这一批要几个**能上架的**（凑够才停：不够会继续往下抓、往下翻页）
5. **输出目录**：结果写这里，建议一个固定的空文件夹
6. **定价规则**：1.2 / 1.5 / 2.0，或 `9-20 +10 / 20.01以上×1.5`（阶梯规则）
7. **结果顺序**：默认只把通过商品写进表；勾选「跳过的商品也写一行」后，通过行排前面，
   跳过行统一放在后面，跳过原因写在备注并带 `跳过：` 前缀
8. **表格显示**：评分、销量、库存列保留用于筛选，但默认隐藏
9. **同系列商品**：一条链接里的多个色块（每个色块是独立商品）自动抓几个（默认 3，含第一个）
10. **变体个数**：每个商品里挑几个规格变体（尺寸/规格那种），默认 3
11. **价格区间**：快捷选「澳洲站 9-30（AU$）」或「美国站 10-35（$）」，也可以自己填
12. **最低评分 / 最低库存**：星级低于 4.0 不抓（填 0 = 不看）、每个变体库存至少 10 件才要；
   旁边「没评分的也跳过」勾上，连没有评价的商品也不要
13. **禁品/大牌**：默认不抓 kid、精油、洗发水、LV 这类；「追加禁品词」可以自己补；
    右边「不抓 Local（本地仓）」默认勾上
14. **抓取节奏**：稳妥 / 正常 / 快（放慢最不容易被弹验证）
15. **被拦处理**：自动歇一会儿再试（推荐）/ 等我手动处理 / 跳过继续
16. **翻页/筛选**：默认「自动加价格筛选」**打开**（池子更对价，凑够数更快）、「最多翻」= 5；
    「跳过的商品也写一行（含未抓取）」默认**不勾**（表里只留通过商品）
17. 点「开始运行」

另一种模式「按表格里的链接抓」：用现成 xlsx（A=编号、G 列或 B 列放希音链接）逐行抓，
也可以使用桌面模板 `手动链接表.xlsx`；结果写入输出目录的 `选品汇总.xlsx`，工作表按序号区间命名。

## 运行时会怎样

- 自动弹出 Edge 或 Chrome 窗口，逐个打开希音商品页
- **希音弹人机验证 / 要求登录时，去脚本打开的浏览器窗口里处理一下**，脚本会原地等你；
  登录状态会保存在对应浏览器档案里，之后不用重复登
- 每个商品约 8~15 秒；随时可以点「停止」，已经抓到的会先写进表
- 连不上希音（连接被重置）会自动重试 3 次；一直不通多半是被临时限流，歇一会儿或换网络
- 使用 Chrome 时，被拦住可以点「换新会话」：把专用档案改名，下次是全新访客会话
- **抓美国站建议在美国/海外网络上跑**——国内网络访问 `us.shein.com` 会被重定向回澳洲站并要求登录

## 产出

```
输出目录/
├── 选品汇总.xlsx          # 一个工作簿，每批一张表：备份1-20 / 备份21-40 …
│   └── 列：序号 | 选品日期 | 希音sku | 产品图片 | 产品金额 | 运费 | 希音链接 |
│           希音卖家ID | 希音标题 | eBay价格 | 上架店铺 | 变体 | 备注 | 是否上架（日期）| 评分 | 销量 | 库存
├── 1/                     # 每个通过商品一个文件夹
│   ├── 1.jpg … 6.jpg
│   └── 商品信息.txt        # eBay 标题 / 状态 / 颜色 / 变体 / 价格 / 明细 / 卖家 / 链接
└── 2/ …
```

- 编号接着已有内容往下排，**不会覆盖**旧文件夹
- 「产品图片」列内嵌商品主图，「希音链接」是真超链接，点一下跳希音商品页
- 勾选「跳过的商品也写一行（含未抓取）」时，跳过商品才写入汇总表，
  并在「备注」里写清楚原因（价格太高 / 低于下限 / 没有在库变体 / 疑似重复 …）

## 文件说明

| 文件 | 作用 |
|---|---|
| `ebay_tool.py` | 主程序：界面、选品流程、图片下载、xlsx 读写（含内嵌图片和超链接） |
| `core_rules.py` | 标题规则、价格工具、xlsx 读取 |
| `shein_fetch.py` | 希音抓取（Chrome / Edge DevTools Protocol，跨平台） |
| `run.bat` / `启动.command` | Windows / macOS 双击启动 |
| `打包.bat` | Windows 本地打包成 exe |
| `tools/merge_results.py` | 开发用：把一份结果并进另一个输出目录（编号接续） |
| `tools/repair_images.py` | 维护工具：从商品文件夹补回汇总表中缺失的图片 |
| `tools/repair_links.py` | 维护工具：修复汇总表中失效或显示为标题的希音链接 |
| `CODE_MAP.md` | 代码地图：每个文件管什么、每类代码在哪 |
| `使用说明_同事版.txt` | 给同事看的简版说明（会一起打进压缩包） |
| `.github/workflows/build.yml` | 打 tag 时自动出三平台安装包并挂 Release |
| `_chrome_profile/` | 抓取用的独立 Chrome 档案（存登录状态，别删、别上传） |
| `_edge_profile/` | Edge 当前会话的抓取副本（保留登录和优惠价格，别上传） |
| `_已选过记录.txt` | 工具自己的全局去重记录（本地生成，别上传） |

## 发版流程

1. 改完代码、本地跑通（Windows 上双击 `打包.bat` 可以先本地试打 exe）
2. 提交推送
3. 打 tag 并推送：

```
git tag v1.0.0
git push origin v1.0.0
```

4. GitHub Actions 自动在 Windows / macOS(Apple 芯片) / macOS(Intel) 三个环境打包，
   把压缩包挂到 Release 上，同事去 Releases 页面下载即可
5. 想先试跑不打 tag：到 Actions 页面点「Run workflow」，产物在本次运行的 Artifacts 里

## 常见问题

- **提示缺 websocket-client / Pillow**：`pip install -r requirements.txt`
- **浏览器起不来 / 端口被占**：先关闭同档案的浏览器再跑；界面上「调试端口」也可以改（默认 9223）
- **写不进 `选品汇总.xlsx`**：多半是你正用 Excel 开着它；关掉即可，脚本也会自动改写成
  `选品汇总_日期时间.xlsx`
- **提示「这个输出目录已经有一个任务在跑了」**：同一个目录只允许一个任务；确认旧任务已经关了的话，
  点「强制停止」就能解锁
- **macOS 提示「无法打开，因为无法验证开发者」**：右键 →「打开」；或终端执行
  `xattr -dr com.apple.quarantine /Applications/SHEIN选品工具.app`
- **Mac 双击 `启动.command` 没反应**：终端里执行一次 `chmod +x 启动.command`
- **一直弹人机验证**：在脚本打开的浏览器窗口里过一次，或把节奏调成「稳妥」
