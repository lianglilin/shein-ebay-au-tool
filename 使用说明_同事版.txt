SHEIN -> eBay 选品工具   使用说明（同事版）
==============================================
支持 Windows 10/11（64 位）和 macOS（Apple 芯片 / Intel）

一、怎么装
  去仓库的 Releases 页面，按你的系统下载对应压缩包，解压即用（不需要装 Python）：
     Windows   ->  SHEIN选品工具-Windows-x64.zip         解压后双击 SHEIN选品工具.exe
     Mac(M系列) ->  SHEIN选品工具-macOS-arm64.zip         解压后把 .app 拖进「应用程序」
     Mac(Intel) ->  SHEIN选品工具-macOS-x86_64.zip        同上
     （不知道自己是哪种 Mac：左上角 苹果标 ->「关于本机」-> 芯片/处理器）

  推荐安装 Microsoft Edge；也支持 Google Chrome。

  ★ Mac 第一次打开：右键点 .app ->「打开」-> 再点「打开」
    （未签名，直接双击会被系统拦一次，只需这一次）
    如果提示「已损坏/无法验证」：打开「终端」执行一次
      xattr -dr com.apple.quarantine /Applications/SHEIN选品工具.app

  ★ 数据存放位置
    Windows：exe 同目录的 _chrome_profile 文件夹（登录状态存在这里，别删）
    Mac    ：～/Library/Application Support/SHEIN选品工具/

二、怎么跑
  1) 抓取模式：默认「从希音分类/搜索页自动抓商品」
  2) 分类/搜索页：填希音的**分类页或搜索页**链接，别填首页！
       （首页没有商品卡片，会显示「一个商品都没抓到」）
       澳洲站例：https://au.shein.com/Beauty-Health-c-1864.html
       美国站例：https://us.shein.com/Women-Dresses-c-12472.html
  3) 抓取个数：这一批要几个**能上架的**（凑够才停：不够会继续往下抓、往下翻页）
  4) 输出目录：结果写哪里，建议固定一个空文件夹（一直用同一个，去重效果最好）
  5) 定价规则：1.2 / 1.5 / 2.0，或 9-20 +10 / 20.01以上×1.5（阶梯规则）
  6) 价格区间：右边「快捷」直接选
       澳洲站 9-30（AU$）   美国站 10-35（$）
  7) 同系列商品：一条链接里的多个色块（每个色块是独立商品）抓几个，默认 3（含第一个）
  8) 变体个数：每个商品里挑几个规格变体（尺寸/规格那种），默认 3（不够就有多少挑多少）
  9) 最低评分：商品星级低于这个分就不抓（默认 4.0，填 0 = 不看评分）；
     旁边「没评分的也跳过」勾上，连没有评价的也不要
 10) 最低库存：每个变体库存至少 10 件才要（希音显示 Only N left 就是库存紧张，这类不抓）
 11) 禁品/大牌：默认不抓 kid（儿童）、精油香薰、洗发水护发素、LV/Chanel/Nike 这类大牌；
     「追加禁品词」可以自己补；右边「不抓 Local（本地仓）」默认勾上
 12) 抓取节奏：默认「稳妥（慢）」——每个商品间隔 10~20 秒、每 6 个再歇 30~60 秒。
     手动慢慢看不会被拦，所以故意放慢；想快就选「正常」或「快」（越快越容易被弹验证）
 13) 被拦处理：默认「自动歇一会儿再试（不登录）」——被拦就歇几分钟再用访客身份重试
 14) 点「开始运行」
     浏览器默认选 Edge：工具会复制当前 Edge 的 Default 档案，保留登录/Cookie
     和页面优惠价格。第一次使用会关闭正常 Edge 再以抓取模式重新拉起，
     运行前先保存 Edge 中正在编辑的内容。
     补充：默认「搜索页自动加价格筛选」是打开的（页面上只显示 9-30 的商品，池子更对价、
           凑够数更快），「最多翻」= 5；抓取顺序仍然严格按页面顺序（左上→右下）。
           「跳过的商品也写一行（含未抓取）」默认不勾：表里只留通过商品，
            商品页内被库存/评分等筛掉的，以及卡面价超区间的，都不再写进表。

三、运行中
  - 会自动弹出 Edge 或 Chrome 窗口，逐个打开希音商品页
  - 希音弹人机验证 / 要求登录时，日志会提示「[需要人工] …」，
    请在脚本打开的浏览器窗口里手动处理一下，脚本会原地等你
  - 每个商品约 10 秒；随时可以点「停止」，已经抓到的会先写进表
  - 「强制停止」= 立刻停 + 解锁输出目录（上次任务卡住时用它）
  - 「换新会话」= 仅对 Chrome 专用档案生效；Edge 使用当前档案副本
  - 别同时开两个：同一个输出目录只允许一个任务

四、产出
  - 选品汇总.xlsx：两种抓取模式都写入这个工作簿，按编号分工作表（备份1-20、备份21-40 …），
    每跑一批自动新建一张表往后接，不会覆盖
    列：序号 | 选品日期 | 希音sku | 产品图片 | 产品金额 | 运费 | 希音链接 |
        希音卖家ID | 希音标题 | eBay价格 | 上架店铺 | 变体 | 备注 | 是否上架（日期）| 评分 | 销量 | 库存
    默认只写通过商品。勾选「跳过的商品也写一行（含未抓取）」后，
    通过行排前面、跳过行放后面；跳过备注以「跳过：」开头
  - 每个通过商品一个文件夹（名字 = 序号）：
    1.jpg ~ 6.jpg + 商品信息.txt（eBay 标题 / 状态 / 颜色 / 变体 / 价格 / 明细 / 卖家 / 链接）

五、小提醒
  - Windows 上杀毒软件（360/火绒）可能误报，加个信任就行
  - 价格规则：澳洲站希音价 9~30（低于 9 不包邮）、美国站 10~35；
    不在区间的会在「备注」里写原因
  - 美国站的价格是美元（$），别按澳元的区间填
  - 抓美国站建议在美国/海外网络跑（国内网络访问 us.shein.com 会被重定向回澳洲站并要求登录）
  - 一次抓很多（比如 200 个）要跑一个多小时、中途容易被弹验证；
    建议分批发（一轮 30 个，跑完歇几分钟再来），编号和表格会自动往后接
  - 希音的「条款/Cookie 更新」弹窗脚本会自动点掉（日志会写）；
    如果弹的是登录页，就用你自己的号在脚本打开的浏览器窗口里登一次
  - 希音自己的报错页（Oops / Something went wrong）脚本会自动刷新重试 3 次
  - 「评分/销量/库存」三列写在表尾：评分像 `4.82（1000条）`，销量像 `700+`，库存是选中变体里最少的那个数
