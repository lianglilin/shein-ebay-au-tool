SHEIN -> eBay AU 选品工具  v0.3.0   使用说明
==========================================

一、文件夹里有什么
  ebay_tool.py       主程序（run.bat 就是跑它）
  core_rules.py      标题规则 / 表格读写 / 价格工具
  shein_fetch.py     希音商品详情抓取模块
  run.bat            双击启动
  README.md          给 GitHub 看的项目说明
  requirements.txt   依赖（抓取装 websocket-client；图片预览装 Pillow）
  _chrome_profile\   抓取用的独立 Chrome 档案（存着登录状态，别删）

二、两种抓取模式
  A. 从希音分类/搜索页自动抓商品（默认，推荐）
     - 「分类/搜索页」填希音的分类页或搜索页链接，例如
       https://au.shein.com/Beauty-Health-c-1864.html
     - 「抓取个数」填你要几个商品（比如 10 / 30 / 50）
     - 「同系列商品」：一条链接挂了多个色块（希音把同系列的商品挂在同一条链接里，
       每个色块其实是独立商品）时，自动抓几个，默认 3
     - 脚本自己翻页找商品 → 逐个打开 → 抓变体/价格/图片 → 出汇总表
  B. 按表格里的链接抓
     - 用你手上那份 xlsx（AU希音链接 - LLL.xlsx）里的链接逐行抓
     - 也可以直接使用桌面上的「手动链接表.xlsx」：A 列序号，B 列粘贴希音链接
     - 「工作表」选对应业务分组，「抓取条数上限」0 = 全部
     - A 列有手填序号就沿用；没有序号才按输出目录接着排
     - 结果写入输出目录的「选品汇总.xlsx」，工作表名按序号区间生成

  两种模式都要先选「输出目录」和「定价规则」，然后点「开始运行」。
  规则：1.2 / 1.5 / 2.0，或 9-20 +10 / 20.01以上×1.5（阶梯规则）

三、运行时会怎样
  - 会自动弹出 Edge 或 Chrome 窗口，逐个打开希音商品页
  - 希音弹人机验证时，请在脚本打开的浏览器窗口里手动过一下，脚本会一直等
  - 每个商品约 8~15 秒（含下载 6 张图）
  - 关掉程序不会关掉浏览器；下次运行会直接接管已经开着的那个
  - 界面是后台线程跑的，不会再出现「未响应」；跑的时候可以点「停止」，
    已经抓到的会先写进表

四、产出
  模式 A 产出一个工作簿：选品汇总.xlsx
    里面按编号区间分工作表：备份109-125 / 备份126-150 …
    跑下一批的时候自动新建一张表往后接，不会覆盖，也不会攒一堆文件
    列顺序跟老板那份一样：
     序号 | 选品日期 | 希音sku | 产品图片 | 产品金额 | 运费 | 希音链接 |
     希音卖家ID | 希音标题 | eBay价格 | 上架店铺 | 变体 | 备注 | 是否上架（日期）
     - 「产品图片」列内嵌商品主图
     - 「希音链接」是真超链接，点一下直接跳到希音商品页
     - 默认只写通过商品；勾选「跳过的商品也写一行（含未抓取）」后才写跳过商品
     - 写跳过商品时，通过行排前面、跳过行放后面；跳过备注以「跳过：」开头
  模式 B 也写入：选品汇总.xlsx
    工作表名例如：备份35-45；和模式 A 使用同一套 17 列模板
  两种模式都会给每个通过商品建一个文件夹（名字 = 序号）：
     1.jpg 2.jpg ... + 商品信息.txt
     商品信息.txt 内容：eBay标题 / 变体 / 价格 / 每个变体明细 / 卖家 / 链接 / 图片数 / 备注

五、规则（和之前对过的一致）
  - 价格：希音价 9~30。低于 9 不包邮，高于 30 没利润 → 跳过
  - 变体：随机挑 2~3 个「有库存」且「每个价格都在区间内」的变体；无库存不抓
  - eBay 价 = 希音价 × 系数（运费不用管，9 以上网站包邮）
  - 标题：≤80 字符；去掉 1pc / 1 pcs 这种一件代发标记（3pcs、15pcs 这种真实件数保留）、
          品牌词、垃圾词、风险词；美式拼写改澳式（organizer→organiser、gray→grey…）
  - 标题里的 2/3 Tier、6/8/12/20 Colours 这种多选：能从选中的变体看出来，就定成一个值
          （比如定成 2 Tier）；看不出来就保留原样，在备注里提醒，并把每一个版本的
          完整标题都写在商品信息.txt 的「备选标题」下面，你挑一个用
  - 去重：自动读你的主表（所有工作表）+ 输出目录里已有的汇总表和商品文件夹，
          已经出现过的商品不再重复上；实在重复了会在备注写「疑似重复」
  - 编号：接着已有内容往下排（表格最后一行 / 目录里最大编号 +1），绝不覆盖旧文件夹

六、常见问题
  - 提示 websocket-client / Pillow 未安装：pip install -r requirements.txt
  - 浏览器起不来：先关闭同档案的浏览器再运行（调试端口被占用时会尝试接管）
  - 端口冲突：界面上的「调试端口」改个数（默认 9223）
  - 分类页商品太少：脚本会自己往下滚翻页；滚不动了会停。想多抓就多点几次运行
  - 一直提示连不上 / 连接被断开：希音临时限流了，脚本会自动重试 3 次；
    还不行就歇 10~30 分钟，或者换个网络（手机热点）再跑
  - 写不进 选品汇总.xlsx：多半是 Excel 正开着这个文件，关掉即可；
    脚本也会自动改写成 选品汇总_日期时间.xlsx
